# CasserCodePIN - PHP

Version en PHP du programme de recherche d'un code PIN par force brute.

## Objectif

Le programme génère un code PIN aléatoire compris entre 0 et 9999.

Il teste ensuite les différentes valeurs une par une jusqu'à trouver le bon code.

## Fonctionnement

Le programme :

- génère un code PIN aléatoire ;
- teste les nombres de 0 à 9999 ;
- compare chaque nombre avec le code secret ;
- s'arrête lorsque le code est trouvé ;
- affiche le temps d'exécution du programme.

## Langage utilisé

- PHP
